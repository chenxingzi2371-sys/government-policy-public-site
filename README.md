# 政府项目申报及涉企政策检索

公开网址：<https://chenxingzi2371-sys.github.io/government-policy-public-site/>

静态公开网站，基于官方公告的筛选元数据及原文链接；无需登录。

使用北京时间自然日检索。官网公开日期用于检索，文件发文日期独立展示。每个条目的完整标题直接跳转政府官方网站；资格、适用范围及延期请以原文为准。

部署到GitHub Pages：Settings → Pages → Source → GitHub Actions，运行仓库中的Deploy工作流。网站不会读取私有生产台账或任何Secrets。

数据缺失、采集失败、日期待核验及缺少查询范围检查记录，不等于“没有更新”。页面显示最后成功采集时间，异常时保留上次成功数据。
